Margins of error. Each standard error is the sample standard deviation (n - 1) of the per-problem figures
over the square root of the number of problems at that depth (n/a with one problem): for every score, and
for the model minus each program on the same problems. Beside the count of problems only the model gets,
the count expected if the model's successes were unrelated to the program's is m x p (m problems the
program misses, p the share the model gets), with standard error sqrt(m p (1 - p)). In the same-wrong-moves
table each is across the problems with a wrong try (n/a with fewer than two), because the tries on one
problem are not independent. These margins reflect the choice of test problems only; for the surface
readers they do not say what a different training set would give. With 4 depths, an occasional gap of two
standard errors is expected by luck alone.
